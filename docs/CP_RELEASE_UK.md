# Під’їзди CP — прийнята Visual3

База патча: `76ee7444eea61904dc93cc2384793d5aa339fc54`, гілка `full_circuit`.
Інтегровано прийнятий після проїзду пакет `CP-Approaches-Visual3.zip`.
Усі вісім JSON перенесено побайтово, без повторної генерації геометрії.

## Що входить

- MF–CW, MF і CW живляться від IMW1500.
- Під’їзд CP з IMW деелектрифіковано до старої нейтральної вставки.
- На під’їзді від CW прокладена звичайна одинарна мережа 1500 В;
  перед західною горловиною додана окрема нейтральна вставка.
- Південний заїзд укорочений; закінчення та знаки відповідають Visual3.
- Парки CP збережені з живленням CP750. Остаточні правки опор,
  проводу біля стрілки та сторін знаків включені.

Дані містяться в `unity_project/Assets/Catenary/Scenery/`.
Нові ресурси: `scenery_CP-CW[IMW].json` і `scenery_[CP]![CW-MF].json`.
Для них додані унікальні GUID та `assetBundleName: catenary`.
GUID шести змінених існуючих ресурсів збережені.
У мережі тепер 50 розстановок і 14 570 об’єктів.

## Застосування

У корені робочої копії, без конфліктних локальних змін:

```powershell
git apply --check CP-Approaches-Visual3-76ee744.patch
git apply CP-Approaches-Visual3-76ee744.patch
python tools/verify_network_release.py
python tools/validate_project.py
```

Для точного порівняння з перевіреним у грі архівом:

```powershell
python tools/verify_network_release.py --cp-accepted-zip CP-Approaches-Visual3.zip
```

Попереднє порівняння з архівом мережі 6 м через `--accepted-zip`
залишається доступним. Його 28 накладок і схема розподілу не змінені.

## Збирання та встановлення

1. У Unity **2019.4.41f2** відкрий `unity_project` і виконай
   **Catenary → Export OCS**.
2. Збери проєкт через `BUILD.cmd` або `tools/Build.ps1`.
3. Закрий гру. Після встановлення нового білда перенеси ці тестові файли
   з `Scenery` встановленого мода у резервну папку поза модом:

```text
scenery_cp-cw[imw].json
scenery_cp-imw[imw].json
scenery_cp.json
scenery_cw-mf[cp].json
scenery_cw.json
scenery_mf.json
scenery_[cp]![cw-mf].json
scenery_[cp]![imw].json
```

Регістр імен не має значення. У новому бандлі ці розстановки вже вбудовані;
залишені накладки перекриватимуть їх. Параметр `included_scenery` залишай `null`.
2WE3 bridge і код симуляції цим патчем не змінюються.

## Перевірки

Інтеграція перевіряє всі значення, порядок, кількість об’єктів та байти восьми
прийнятих файлів. Загальна перевірка також контролює визначення підстанцій,
посилання живлення, метадані Unity та попередню мережу GF / 6 м.

Геометрію Visual3 користувач перевірив і прийняв у грі. Unity-експорт і запуск
заново зібраного бандла під час підготовки патча не виконувалися.
