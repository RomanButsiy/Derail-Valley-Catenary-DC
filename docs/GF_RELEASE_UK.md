# Коридор і станція GF — прийнята версія

Інтегровано завершену станцію GF, підходи HB–GF–CME/IME і вихід до трикутника
в напрямку SM/FF. Профілі відкритих перегонів підняті до прийнятих 6 м;
станція GF зберігає перевірені користувачем висоти й бокові рейки.

SM–HB проходить через N02, HB–GF через перенесену N08, GF–CME/IME через N07.
N01 перенесена на пряму ділянку в напрямку SM. Лінія до фізичного розриву
перед FF живиться від GF1500. Парк D і бокові рейки GF використовують GF1100.
Західне кільце, нафтова свердловина та погоджені відгалуження залишаються
деелектрифікованими. Трикутник після станції GF збережений повністю.

## Розподіл ресурсів

Усі файли розташовані в `unity_project/Assets/Catenary/Scenery/`.

| Файл / група | Вміст |
| --- | --- |
| `scenery_GF.json` | Підстанції GF1500/GF1100 та станційна геометрія, включно з рейками й знаками. |
| `scenery_GF-HB[GF].json` | Існуючий коридор з боку HB і доданий підхід до станції. |
| `scenery_GF-SM[GF].json` | Вихід зі станції, тунель і весь погоджений трикутник у напрямку SM/FF. |
| `scenery_[GF]![SM].json` | Перенесена N01, анкери й знаки, включно з кінцями живлених ниток. |
| `scenery_HB-GF[HB].json`, `scenery_IME-GF[CME-IME].json` | Раніше погоджені сторони перегону, тепер із прийнятим профілем 6 м. |
| `scenery_[HB]![GF].json`, `scenery_[GF]![CME-IME].json` | Прийняті N08/N07 з узгодженими висотами. |
| `scenery_SM-FF[SM].json`, `scenery_FF-SM[FF].json`, `scenery_[FF]![SM].json` | Збережені історичні назви ресурсів; живлення перевизначене у полі `substation` кожного дроту. Стара N01 замінена проходом GF1500. |
| `scenery_OWN.json` | Порожній масив: деелектрифікована нафтова свердловина. |

Поділ на файли не створює фізичних стиків або нових перегинів. Усі координати,
довжини, нахили, кріплення, знаки й електричні значення відтворюють прийнятий
`Catenary_6m_Visual2.zip`. GUID існуючих ресурсів збережені; два нові JSON
мають власні `.meta` з міткою `catenary`.

Історичний `audit/phase2_gf.json` описує коридор Visual 3 до робіт на станції;
актуальна повна мережа зафіксована в `audit/network_6m.json`.
