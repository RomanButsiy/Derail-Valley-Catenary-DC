# Catenary DC 0.3.0

The vehicle bridge now uses Knsgf’s 2WE3 controller from v2.8.0 (`03d9de6`).
Compared with the 0.2.0 bridge it includes the upstream gauge response, field
weakening and traction circuit changes. Choose the sandbox model pack (2.3.9)
or the career pack with the custom licence (2.4.0). [2WE3 v2.8.0](https://github.com/Knsgf/Derail_Valley_electric_concept/releases/tag/v2.8.0)

WE-4U InDev-0.3.1 can use the same bridge through the stock Custom Car Loader
Catenary Support importer. Install the WE-4U model and electrics together.
Players who drive only WE-4U can omit the 2WE3 models. [WE-4U](https://github.com/Comrad501/Dv-WE-4U/releases/tag/InDev-0.3.1) · [CatenaryForCCL](https://github.com/Knsgf/CCL-OCS/releases/tag/v1.1.0)

The network includes City West and the Farm–FRC route, the CP triangle and its
OR connection. FRC B1L has a signed wire gap at the water tower. The third
through track has continuous 1500 V overhead.

Install `Derail-Valley-Catenary-DC-0.3.0.zip`. For either locomotive, add
`Derail-Valley-Catenary-DC-2WE3-Bridge-0.3.0.zip`. Move the original
Catenary-DC mod and the previous bridge folder out of `Mods` before installing.
[Installation and dependencies](INSTALL_RELEASE_UK.md)
