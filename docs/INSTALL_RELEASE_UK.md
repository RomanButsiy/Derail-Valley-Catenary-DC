# Встановлення Catenary DC 0.3.0

1. Закрий Derail Valley. Перемісти оригінальний мод Knsgf `Catenary-DC` і попередню папку `Derail-Valley-Catenary-DC-2WE3-Bridge` за межі `Mods`. У новому bridge змінилося ім’я DLL, тому заміни всю його папку.
2. Установи `Derail-Valley-Catenary-DC-0.3.0.zip` із розділу **Assets** через Unity Mod Manager 0.27.3 або новіший. Цього достатньо для огляду мережі на стандартній карті. [Релізи Catenary DC](https://github.com/RomanButsiy/Derail-Valley-Catenary-DC/releases)
3. Для їзди на 2WE3 або WE-4U встанови з того самого релізу `Derail-Valley-Catenary-DC-2WE3-Bridge-0.3.0.zip`, а також Custom Car Loader із його залежностями. Далі вибери потрібні моделі. [Custom Car Loader](https://www.nexusmods.com/derailvalley/mods/324)

| Локомотив | Що встановити додатково |
|---|---|
| 2WE3 для пісочниці | [2WE3CCL.zip, версія пакета 2.3.9](https://github.com/Knsgf/Derail_Valley_electric_concept/releases/download/v2.8.0/2WE3CCL.zip) |
| 2WE3 із ліцензією для кар’єри | [2WE3CCL-licence.zip, версія пакета 2.4.0](https://github.com/Knsgf/Derail_Valley_electric_concept/releases/download/v2.8.0/2WE3CCL-licence.zip) і [DV Custom Licenses](https://github.com/WhistleWiz/dv-custom-licenses/releases) |
| WE-4U (EU07) | Обидві папки `EU07` та `EU07Electrics` із [WE-4U InDev-0.3.1](https://github.com/Comrad501/Dv-WE-4U/releases/tag/InDev-0.3.1), [DV Custom Licenses](https://github.com/WhistleWiz/dv-custom-licenses/releases) та [CatenaryForCCL.zip](https://github.com/Knsgf/CCL-OCS/releases/download/v1.1.0/CatenaryForCCL.zip) |

Для 2WE3 вибери один із двох варіантів. Для WE-4U пакети моделей 2WE3 необов’язкові. Оригінальний архів автора `Catenary-DC.zip` містить окрему симуляцію мережі й конфліктує з bridge цього релізу.

Після встановлення перезапусти гру. У меню UMM (Ctrl+F10) для їзди мають бути активні **Derail Valley Catenary DC** та **Catenary DC — 2WE3 and CCL vehicle bridge**. Для WE-4U перевір також **Custom Car Loader Catenary Support**, **WE-4U (EU07)** і **WE-4U (EU07) electrics**.
