# Як установити Catenary DC

Потрібна гра **Derail Valley** зі встановленим **Unity Mod Manager**.

1. **Закрий гру.** Якщо раніше встановлював оригінальний авторський мод
   `Catenary-DC`, перемісти його папку за межі `Mods`, щоб моди не конфліктували.
2. Відкрий [сторінку релізів](https://github.com/RomanButsiy/Derail-Valley-Catenary-DC/releases)
   і в розділі **Assets** завантаж `Derail-Valley-Catenary-DC-0.2.0.zip`.
3. Відкрий **Unity Mod Manager**, вибери **Derail Valley** та на вкладці
   **Mods** установи завантажений ZIP.
4. Запусти гру й переконайся, що мод увімкнений у меню Unity Mod Manager.

## Якщо хочеш їздити на 2WE3

Додатково потрібні:

- **Custom Car Loader (CCL)** — мод для завантаження локомотивів.
- [**2WE3CCL.zip**](https://github.com/Knsgf/Derail_Valley_electric_concept/releases/download/v2.5.4/2WE3CCL.zip)
  — моделі локомотива.
- **Derail-Valley-Catenary-DC-2WE3-Bridge-0.2.0.zip** — завантаж із того самого
  релізу Catenary DC та встанови через Unity Mod Manager.

Після встановлення перезапусти гру. Якщо 2WE3 не потрібен, ці доповнення можна
не встановлювати.

**Зверни увагу:** завантажуй готові ZIP із Assets, а не **Source code**.
Мод розрахований на стандартну карту; **Double-Tracked Valley не підтримується**.
