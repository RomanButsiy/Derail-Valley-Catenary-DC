# FRC · Visual2

У бандл `catenary` включено чотири файли з прийнятого архіву `FRC_Visual2.zip`. База патча — `full_circuit`, коміт `ae5bfbe951fab20b1bd3b5ca01004b2567442bc1`.

| Файл | Ділянка |
| --- | --- |
| `scenery_FRC-CP-OR.json` | Мережа від ферми через FRC до трикутника CP і підходу OR, підстанція FRC1500 та знаки |
| `scenery_FM-SM[SM].json` | Фермерська стрілка й прилеглі прольоти |
| `scenery_CW-MF[CP].json` | Опори на стиках двох гілок трикутника CP |
| `scenery_OR.json` | Нейтральна вставка та приєднання до мережі OR 750 В |

## Збирання й оновлення

1. З кореня репозиторію виконай `python tools/verify_network_release.py`. Якщо під рукою є прийнятий архів, додай `--frc-accepted-zip FRC_Visual2.zip` для побайтової перевірки.
2. Відкрий `unity_project` у Unity 2019.4.41f2, виконай **Catenary → Export OCS** і збери мод за [інструкцією збирання](BUILD_UK.md).
3. Після встановлення нової збірки перемісти з папки `Scenery` мода за її межі зовнішні копії чотирьох файлів із таблиці. Це стосується також версії `scenery_CW-MF[CP].json` із попереднього тесту CW.

Для повторної перевірки геометрії в архіві Visual2 є генератор та заміри колій у `Source`, а в `Review` — результати перевірок контакту, висот, відтяжок і знаків.
